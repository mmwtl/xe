# ХЕ.СЧЁТ

PWA для приблизительной оценки хлебных единиц по фотографии или текстовому
описанию. Интерфейс работает на Next.js, а анализ выполняется Gemini через
серверный API-маршрут.

> [!CAUTION]
> Результат приблизительный. Приложение не является медицинским изделием и не
> должно быть единственным основанием для расчёта дозировки инсулина.

## Возможности

- до трёх фотографий одного блюда в одном запросе или текстовое описание;
- пересчёт углеводов по формуле `1 ХЕ = 12 г углеводов`;
- поддержка JPG, PNG, WebP, HEIC и HEIF с серверной проверкой сигнатуры;
- адаптивный PWA-интерфейс для компьютера, Android и iPhone;
- fallback-цепочка моделей при ответе Gemini `429`;
- отсутствие регистрации, базы данных и постоянного хранения фотографий;
- API-ключ доступен только серверу и не попадает в клиентский JavaScript.

## Требования

- Node.js 22.13 или новее;
- npm;
- Gemini API key из [Google AI Studio](https://aistudio.google.com/apikey).

## Локальный запуск

```bash
git clone <URL-репозитория>
cd <каталог-репозитория>
npm ci
cp .env.example .env.local
```

Укажите ключ в `.env.local`:

```dotenv
GEMINI_API_KEY=ваш_ключ
```

Запустите приложение:

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). После изменения
`.env.local` перезапустите сервер.

### Проверка интерфейса без Gemini

Добавьте в `.env.local`:

```dotenv
GEMINI_MOCK=1
```

В mock-режиме API возвращает тестовый результат и не отправляет данные Google.

## Настройка моделей

Основная модель и fallback-цепочка задаются без изменения кода:

```dotenv
GEMINI_MODEL=gemini-3.6-flash
GEMINI_FALLBACK_MODELS=gemini-3.5-flash,gemini-3.5-flash-lite
```

Fallback применяется только при ограничении частоты запросов (`429`). Он не
скрывает неверный ключ, некорректный запрос или сбой обработки. Актуальные
названия моделей сверяйте с
[документацией Gemini](https://ai.google.dev/gemini-api/docs/models).

## Проверки

```bash
npm run check
npm run build
```

Те же проверки автоматически выполняются в GitHub Actions для pull request и
push в `main`.

## PWA и мобильные устройства

Service worker регистрируется только в production-режиме:

```bash
npm run build
npm start
```

Для проверки с другого устройства в локальной сети:

```bash
npm run dev:mobile
```

Для локального HTTPS:

```bash
npm run dev:https
```

Установка PWA и service worker требуют безопасного контекста: `localhost` или
HTTPS. Самоподписанный сертификат нужно вручную сделать доверенным на тестовом
устройстве. На iPhone установка выполняется в Safari через
`Поделиться` → `На экран «Домой»`.

## Данные и ограничения

- Фотографии отправляются в Gemini только после нажатия `Рассчитать ХЕ`.
- Репозиторий и приложение не сохраняют фотографии и результаты в базе данных.
- Скрытые ингредиенты, масло, сахар и соусы могут быть не распознаны.
- Никогда не коммитьте `.env.local` и реальные API-ключи.
