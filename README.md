# ХЕ.СЧЁТ

PWA для приблизительной оценки хлебных единиц по фотографии или текстовому
описанию. Интерфейс работает на Next.js, а анализ выполняется Gemini через
серверный API-маршрут.

> [!CAUTION]
> Результат приблизительный. Приложение не является медицинским изделием и не
> должно быть единственным основанием для расчёта дозировки инсулина.

## Возможности

- съёмка задней камерой или выбор готовых изображений;
- голосовой ввод описания блюда с последующей проверкой текста;
- до трёх фотографий одного блюда в одном запросе или текстовое описание;
- пересчёт углеводов по формуле `1 ХЕ = 12 г углеводов`;
- поддержка JPG, PNG, WebP, HEIC и HEIF с серверной проверкой сигнатуры;
- адаптивный PWA-интерфейс для компьютера, Android и iPhone;
- fallback-цепочка моделей при ответе Gemini `429`;
- локальная история запросов и ответов без регистрации;
- защищённый серверный журнал новых запросов и ответов для администратора;
- API-ключ доступен только серверу и не попадает в клиентский JavaScript.

## Требования

- Node.js 22.13 или новее;
- npm;
- Gemini API key из [Google AI Studio](https://aistudio.google.com/apikey).

## Локальный запуск

```bash
git clone <URL-репозитория>
cd <каталог-репозитория>
npm ci
cp .env.example .env.local
```

Укажите ключ в `.env.local`:

```dotenv
GEMINI_API_KEY=ваш_ключ
ADMIN_PASSWORD=длинный_уникальный_пароль
ADMIN_SESSION_SECRET=случайный_секрет
```

Запустите приложение:

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). После изменения
`.env.local` перезапустите сервер.

### Проверка интерфейса без Gemini

Добавьте в `.env.local`:

```dotenv
GEMINI_MOCK=1
```

В mock-режиме API возвращает тестовый результат и не отправляет данные Google.

## Настройка моделей

Основная модель и fallback-цепочка задаются без изменения кода:

```dotenv
GEMINI_MODEL=gemini-3.6-flash
GEMINI_FALLBACK_MODELS=gemini-3.5-flash,gemini-3.5-flash-lite
```

Fallback применяется только при ограничении частоты запросов (`429`). Он не
скрывает неверный ключ, некорректный запрос или сбой обработки. Актуальные
названия моделей сверяйте с
[документацией Gemini](https://ai.google.dev/gemini-api/docs/models).

## Админ-журнал

Страница `/admin` показывает новые запросы к `/api/analyze`, ответы Gemini и
ошибки. Для каждого фото журнал хранит имя, MIME-тип, размер и компактное
WebP-превью; оригинал в аудит-хранилище не копируется. IP-адреса и API-ключи не
сохраняются.

Журнал рассчитан на private [Vercel Blob](https://vercel.com/docs/vercel-blob):

1. В Vercel откройте `Storage` → `Create Database` → `Blob`.
2. Выберите доступ `Private` и подключите store к проекту.
3. Убедитесь, что в Production доступны `BLOB_READ_WRITE_TOKEN`,
   `ADMIN_PASSWORD` и `ADMIN_SESSION_SECRET`.
4. Выполните новый deployment и откройте `/admin`.

Локально Blob также работает с `BLOB_READ_WRITE_TOKEN` из `.env.local`.
Без подключённого Blob расчёты продолжают работать, но журнал не заполняется.
Старую IndexedDB-историю устройств сервер получить не может.

Для проверки админ-интерфейса без Blob добавьте `AUDIT_MOCK=1`. Этот режим
возвращает несколько демонстрационных записей и ничего не сохраняет.

Blob выбран вместо реляционной базы для небольшого числа пользователей:
каждый анализ создаёт два JSON-объекта, а админка загружает журнал страницами
по 25 записей. Поиск и фильтры применяются к уже загруженным страницам.

## PWA и мобильные устройства

Service worker регистрируется только в production-режиме:

```bash
npm run build
npm start
```

Для проверки с другого устройства в локальной сети:

```bash
npm run dev:mobile
```

Для локального HTTPS:

```bash
npm run dev:https
```

Установка PWA и service worker требуют безопасного контекста: `localhost` или
HTTPS. Самоподписанный сертификат нужно вручную сделать доверенным на тестовом
устройстве. На iPhone установка выполняется в Safari через
`Поделиться` → `На экран «Домой»`.

## Данные и ограничения

- Фотографии отправляются в Gemini только после нажатия `Рассчитать ХЕ`.
- Голосовой ввод добавляет распознанный текст в поле описания и не запускает
  расчёт автоматически. В зависимости от браузера аудио может обрабатываться
  его внешним сервисом распознавания; голосовой ввод не считается полностью
  локальным и требует разрешения на микрофон.
- Запросы, ответы и до трёх фото сохраняются в IndexedDB браузера на текущем устройстве.
- При настроенном Vercel Blob текст запроса, ответ, технические метаданные и
  уменьшенное превью фотографий также сохраняются в закрытом серверном журнале.
- Историю можно полностью удалить из экрана `История`.
- Очистка данных сайта в браузере также удаляет всю историю.
- Скрытые ингредиенты, масло, сахар и соусы могут быть не распознаны.
- Никогда не коммитьте `.env.local` и реальные API-ключи.
