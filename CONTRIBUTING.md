# Участие в разработке

## Перед началом

1. Создайте отдельную ветку от `main`.
2. Установите зависимости командой `npm ci`.
3. Скопируйте `.env.example` в `.env.local`.
4. Для работы без внешнего API используйте `GEMINI_MOCK=1`.

Не добавляйте в issues, pull request, коммиты и логи реальные API-ключи,
фотографии пользователей или иные персональные данные.

## Требования к изменениям

- Сохраняйте серверную обработку API-ключа: секрет не должен попадать в
  переменные с префиксом `NEXT_PUBLIC_` или клиентские компоненты.
- Не превращайте оценку ХЕ в медицинскую рекомендацию или расчёт дозы инсулина.
- Для новых форматов загрузки проверяйте содержимое файла на сервере, а не только
  MIME-тип, присланный браузером.
- Обновляйте README при изменении запуска, переменных окружения или поведения
  приложения.

## Проверка pull request

Перед отправкой выполните:

```bash
npm run check
npm run build
```

CI повторит эти команды на Node.js 22.13.
